---
title: Getting started
description: Install the CLI and discover commands.
---

Install with Node.js 22.12+:

```sh
npm install --global avanza-cli
avanza --help
```

Get help for any command and try a public market query without signing in:

```sh
avanza market search --help
avanza market search --query volvo --limit 5
```

For private data, [authenticate](/docs/cli/authentication) first. See the [command reference](/docs/cli/reference) for all topics and available flags.
