`avanza-cli` is an oclif-based terminal interface built on `avanza-ts`. [Install it](/docs/cli/getting-started), [get a TOTP secret](/docs/cli/authentication#getting-a-totp-secret), and read about [session duration](/docs/cli/sessions#session-duration). Browse the [generated command reference](/docs/cli/reference) for commands and flags sourced from oclif help metadata.
