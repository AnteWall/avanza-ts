`AvanzaClient` exposes domain clients as properties. These guides display type tables generated directly from the TypeScript source. Import public types and values from `avanza-ts`, rather than internal paths.

| Guide                                                    | What it covers                                     |
| -------------------------------------------------------- | -------------------------------------------------- |
| [Client and configuration](/docs/sdk/reference/client)   | `AvanzaClient`, options, and errors                |
| [Authentication](/docs/sdk/reference/authentication)     | TOTP, BankID, and sessions                         |
| [Markets and screeners](/docs/sdk/reference/market)      | Market data, instruments, and funds                |
| [Accounts and portfolios](/docs/sdk/reference/portfolio) | Accounts, positions, transactions, and performance |

For every exported interface and type alias, use the [complete generated reference](/docs/sdk/reference/generated). It includes detailed signatures and links between types, such as [`AvanzaClient`](/docs/sdk/reference/generated/classes/AvanzaClient) and [`StockFilter`](/docs/sdk/reference/generated/interfaces/StockFilter).
