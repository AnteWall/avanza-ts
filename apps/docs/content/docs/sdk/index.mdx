`avanza-ts` is an ESM-first TypeScript SDK for Avanza. It owns the HTTP transport and an in-memory session; your application decides how to store credentials and present results.

Start with [installation and your first request](/docs/sdk/getting-started), then read [how to get a TOTP secret](/docs/sdk/authentication#getting-a-totp-secret) and [session duration](/docs/sdk/sessions#session-duration). Browse the [public API](/docs/sdk/reference) and its [generated signatures](/docs/sdk/reference/generated). See [For AI agents](#for-ai-agents) for Markdown versions of these docs.
